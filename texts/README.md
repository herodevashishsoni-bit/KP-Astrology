# Source texts

Reference material for the KP prediction engine. All prediction rules are taken only from these texts.

- `readers/` — K.S. Krishnamurti, KP Readers 1–6
- `magazines/` — KP magazine volumes

Preferred formats: text-based PDF, .txt or .md. Scanned PDFs work but OCR may introduce errors.
- `extracted/` — plain-text versions of every PDF, used for reading and searching. Readers 4 and 5 use a scrambled font encoding in the PDF, so their text was produced by OCR (tesseract, 300 dpi); the rest come from the PDFs' own text layer. Page markers in the OCR files look like `=== PAGE 0012 ===`.
